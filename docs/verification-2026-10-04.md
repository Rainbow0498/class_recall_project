# 第一版交付与验证记录

日期：2026-10-04。代码分支：`codex/biology-workspace`。

## 功能范围

老师单人登录、学生档案及成绩、周课表与单学生课表、单次及有限范围重复排课、图片课表识别与核对导入、冲突确认、系列调课和取消恢复、候选反馈生成与编辑复制、历史最终反馈、课后进度同步、模板设置、部署及备份恢复。

## 验证

- Django 全套 52 项自动化测试：包含真实 SQLite 功能事务、本地假模型 HTTP 契约、版本冲突、并发调课与取消、批次内部冲突、完整数据库恢复、登录密码校验、日历时段及无效输入处理。
- 生产 `check --deploy --fail-level WARNING`、迁移一致性、JavaScript 语法、部署脚本语法与 Git 空白检查。
- 独立 Chrome 浏览器验证 375、768、1280、1440 像素宽度：登录、新增学生、成绩、排课冲突确认、手动保存反馈、模型失败保留笔记、模板设置，无页面横向溢出。
- 补充手机交互：候选不覆盖原稿、明确采用、复制、更新进度、取消范围预览、恢复冲突确认、设置页退出。
- 日历改版浏览器验证：电脑七日网格、手机日网格及日期切换、点击和键盘选择空白时段、修改结束时间、拒绝无效时间、预览确认保存后在网格显示；四种宽度没有页面横向溢出。
- 图片导入新增 17 项测试：视觉请求发送原图及单独模型、不发送学生档案；当前年份与两小时校验、同名选择、档案复用及归档处理、重复跳过、冲突确认及过期重算、用户绑定与 CSRF、失败整批回滚、重复提交幂等、导入课次的调课和取消互不影响、原图临时保留及清除。
- 图片导入浏览器使用用户提供的 JPG 和本地假视觉模型返回的虚构学生记录：六行核对、修改与取消勾选、错误聚焦、同名标签对应姓名、重叠确认、五节课保存到日历、重复导入跳过、返回修改后原图保留；375、768、1280、1440 四种宽度无横向溢出，未发生脚本错误。实际识别准确率尚未验证。
- 浏览器候选交互使用测试响应，后端模型请求另由真实本地 HTTP 服务验证。没有使用用户提供的密钥或消耗真实模型额度。
- 不使用 Docker 的本地生产启动验证：临时独立数据库迁移、老师账号初始化、静态资源收集与生产检查通过；Gunicorn 单 worker / 4 线程运行后，健康接口、登录页、日历脚本和样式均返回 HTTP 200。Ubuntu 脚本通过 Bash 语法检查。

## 独立复核与修复

复核代理检查了完整实现。修复前新增回归测试复现失败，修复后通过：

1. 调课和取消使用版本及状态条件更新，任一记录过期则整批回滚，防止覆盖刚完成课程的反馈、状态与进度快照。
2. 批量调课检查调整后目标课程之间的重叠；确认冲突后才保存。
3. 批量取消先展示实际数量和日期，再使用有时效的签名预览确认；状态或范围变化时拒绝过期确认。

补充对完整恢复后的学生、系列、课程、最终反馈、设置及老师密码的读取验证。初始化命令拒绝示例占位密码。

日历改版与 Ubuntu 直接部署材料经过独立只读复核，未发现需修复的问题。复核确认了单次日期默认、深夜时段上限、重叠课程入口、系统服务读取私有配置及应用自身提供静态资源的行为；服务器启动和 HTTPS 仍留待实际上线验收。

图片导入经过独立只读复核。回归测试先复现再修复：图片中的独立课程不挂到重复排课系列，避免未来范围调课或取消影响其他学生；同名选项显示年级与档案编号，姓名单独赋值；原图短期保留以便校验错误后继续对照。修复后独立重跑 17 项导入测试全部通过，无剩余重大问题。生产启动验证也覆盖新增迁移及图片导入脚本 HTTP 200。

## 实现决定

- 用户已明确要求开始代码并逐模块提交推送，按此连续执行，未再次要求审批计划；若需要修改计划，后续以模块提交调整。
- 使用当前专用仓库的 `codex/biology-workspace` 分支，保留原分支；没有额外创建工作树，代价是当前目录展示开发分支内容。
- 手机退出沿用反馈设置中的现有入口，已通过浏览器验证；代价是需要先打开设置页。
- SQLite 与单 Gunicorn 进程用于单老师第一版，支持系统服务直接运行或容器运行；多人扩展时需要重新评估部署和数据库。

## 尚未验证

本机未安装 Docker，因此未本地构建镜像或运行 Compose；已配置 CI 构建任务，但未将远程 CI 状态作为成功证据。本机为 macOS，Ubuntu 系统服务和 Caddy 安装尚未在目标服务器运行。未登录腾讯云服务器或使用真实百炼密钥；网页访问诊断的外部探测仅显示 HTTP 能重定向、HTTPS 连接超时，具体安全组及本机防火墙配置仍待服务器检查。图片导入使用本地假接口验证，真实视觉识别、模型权限和额度留待服务器上验证。无需 Docker 的上线说明见 `deploy/native/README.md`，可选容器方案见 `deploy/README.md`，正式地址配置为 `www.gyloveyyb.site`。
